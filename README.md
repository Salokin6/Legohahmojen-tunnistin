# Legohahmojen Tunnistin

Python-pohjainen työpöytäsovellus legohahmojen tunnistamiseen kuvatiedostoista tai web-kameralla. Sovellus hyödyntää Microsoft Azure Custom Vision -pilvipalvelua luokitteluun ja CustomTkinter-kirjastoa käyttöliittymään.


## Tekoälyn käyttö sovelluskehityksessä
- Projektin sovelluskoodin luonnostelussa ja ongelmanratkaisussa on käytetty apuna Google Geminin kielimallia.
- Tekijä itse on vastannut arkkitehtuurista, mallin koulutuksesta Azuressa sekä toteutuksen toimivuuden testaamisesta.
